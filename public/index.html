시나리오 실험실

Interim Demo 2의 검증 항목을 반복 실행으로 확인해요. ① 같은 답변에 State가 일관되게 판정되는가 ② 상태가 바뀔 때마다 근거가 있는가 ③ 답변 상태에 맞는 질문이 선택되는가 ④ 질문이 과도하게 반복되지 않는가. 한 번의 실행으로 일반화하지 않도록 같은 시나리오를 여러 번 돌려요.

예상 API 호출: 턴당 약 3~5회 × 반복 횟수. 실행 중에도 다른 탭은 사용할 수 있어요.
